# 3.1 — Infra admin

## Escopo entregue

- Layout `/admin/*` (`AdminLayout`) com navegação própria: sidebar escura com selo **ADMIN** no desktop (design `WebSidebar variant="admin"`), header + abas roláveis no mobile. "Voltar ao app" e logout.
- Guards no router: `RequireRole allow={['admin','super_user']}` no layout; `RequireRole allow={['super_user']}` em `/admin/admins` e `/admin/audit`.
- Quem não tem o papel é **redirecionado** (não vê 403): usuário comum → `/app`, admin em rota de super user → `/admin/exercises`. Um toast explica ("Você não tem permissão…"), via `useForbiddenNotice`.
- Atalho "Painel admin" no app (sidebar desktop, ícone no header mobile), visível só para admin/super user.
- Tabela genérica `DataTable` + `PaginationBar` + controles (`SearchField` com debounce, `Segmented`, `FilterSelect`, `Toggle`, `Pill`) e `useListParams` (busca/filtros/página na URL, com prefixo para duas listas na mesma tela).

## Decisões técnicas

- **Redirect em vez de página 403**: o roadmap aceita os dois; o redirect evita uma tela sem saída. O guard é UX: a API checa o papel no banco a cada request.
- **Papel lido do `/auth/me` no boot**: um admin rebaixado no meio da sessão perde o painel no próximo reload; antes disso, as chamadas já dão 403 e as telas mostram erro.
- **`DataTable` renderiza um layout só** (grid no desktop, cards no mobile) escolhido por `useMediaQuery`, não dois layouts escondidos por CSS: assim texto e controles não aparecem duplicados no DOM (leitores de tela e testes).
- **Estado de lista na URL** (`?q=&status=&page=`, ou `c.page`/`a.page` com prefixo): links compartilháveis e reload preserva os filtros. Mudar filtro volta para a página 1.
- **Painel lateral vs. modal** (exercícios, usuários): o design mostra painel fixo à direita a 1280px. Em `< lg` vira modal, com o mesmo componente.

## Correções transversais

- `shared/ui/Modal`: `aria-labelledby` no título (o diálogo agora tem nome acessível) e `onClose`/`onCancel` ignoram eventos de diálogos aninhados. O React propagava o `close` do diálogo de confirmação até o diálogo pai, que fechava junto (aparecia no mobile, onde o perfil do usuário fica em modal).
- `RequireRole` ganhou `redirectTo`.

## Rotas

## Como testar

`npx playwright test e2e/admin/infra.spec.ts` — sem login → `/login`; usuário → `/app` + aviso; admin sem as áreas de super user; super user com tudo; rebaixado perde o painel no reload; busca/filtro na URL sobrevivem ao reload; sem rolagem horizontal em nenhuma tela admin.
