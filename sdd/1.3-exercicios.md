# 1.3 — Exercícios

## Escopo entregue

- Tela `/app/exercises`: biblioteca (catálogo + personalizados), busca por nome, filtro por grupo muscular e filtro "Personalizados"
- Criação, edição e exclusão de exercício personalizado (modal), restrito ao dono
- `GET /exercises?q=`, `POST /exercises/custom`, `PATCH/DELETE /exercises/custom/:id` — validados contra o backend real rodando localmente

## Decisões técnicas

- **Grupo muscular filtrado no cliente, busca por nome no servidor** — `GET /exercises` não tem endpoint público de grupos musculares (só existe `/admin/muscle-groups`, fase 3). Os chips de filtro são derivados dos valores distintos de `muscleGroup` já presentes na resposta, não de uma lista hardcoded — se o backend adicionar/renomear um grupo, os chips acompanham sem mudança de código. `q` vai para a API a cada mudança do campo de busca; sem debounce porque o catálogo é pequeno (~90 itens) e não há indicação de custo alto no backend.
- **`muscleGroupSlug` derivado do nome de exibição** (`toMuscleGroupSlug`, normaliza acentos/espaços) — a API só devolve o nome (`"Abdomen"`), não o slug, mas exige um `muscleGroupSlug` válido em `POST/PATCH /exercises/custom`. Testado ao vivo: `toMuscleGroupSlug("Abdomen") === "abdomen"` é aceito pelo backend.
- **Edição em modal, não painel lateral fixo** — o comp de design (`Forma Web.dc.html`) mostra um painel fixo ao lado da grade só na versão desktop; a versão mobile não tem equivalente. Um modal cobre os dois breakpoints com um único componente, sem tela duplicada.
- **Grid responsivo único** (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`) em vez de layouts de grade (desktop) e lista (mobile) separados — 1 coluna em mobile já se comporta como lista.

## Como testar

1. `/app/exercises` lista o catálogo real (~90 exercícios) + personalizados do usuário.
2. Buscar por nome filtra via API; chips de grupo muscular filtram no cliente.
3. "Exercício personalizado" abre modal de criação; exercícios criados por você mostram tag "Seu" + botão de editar (catálogo não mostra).
4. Editar um exercício personalizado permite renomear, trocar grupo ou excluir.
